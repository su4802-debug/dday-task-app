⚡ 즉시 발송 (선택)

GitHub 토큰을 등록하면 Supabase가 1분마다 보낼 메일을 확인해 발송기를 바로 깨웁니다 (보통 1~2분 안에 도착). 등록하지 않으면 GitHub 예약 실행에만 의존해 최대 1시간 늦어질 수 있습니다.
토큰: GitHub › Settings › Developer settings › Fine-grained tokens › 이 저장소만 선택 · 권한 Actions: Read and write. 저장한 토큰은 다시 볼 수 없습니다.
